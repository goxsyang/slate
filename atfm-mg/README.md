* 輸出：`out/ATFM_benefits_0840_5994.mp4` — 1920×1080、59.94 fps、H.264 High、BT.709，

## 專案結構

```
index.html            組成頁（1920×1080 舞台）
src/cues.js           口白時間表（59.94 DF 時間碼 → 秒）與字詞錨點
src/kit.js            設計 token（色票/字級）與動畫工具（遮罩文字、計數器、描線、漂浮）
src/chrome.js         各頁眉（小標/標題）與頁尾註解
src/scenes/*.js       三個場景：s1_ground（地面等待）、s2_benefits（效益）、s3_cost（投入與公帑）
assets/*.png          自參考影片擷取並去背的插畫（客機×2、機櫃、停機坪）
tools/clean_asset.py  去除擷取插畫上殘留的淡色圓形殘影
tools/render.mjs      Playwright 逐格輸出（stills / video）
tools/extract_assets.py  從參考影片重新擷取插畫
tools/contact.py      靜態格拼成縮圖表
```

## 重新輸出

```bash
npm install                      # gsap（vendor/ 已附帶可直接用）
bash tools/fetch_fonts.sh        # 選用：完整 Noto Sans TC（改字時需要；否則用 fonts/subset/）
node tools/render.mjs video --out out/ATFM_benefits_0840_5994.mp4
node tools/render.mjs video --review --out out/ATFM_benefits_0840_5994_review.mp4
node tools/render.mjs stills --times 3.5,7.2,20.4 --review   # 單格檢查
```

在瀏覽器直接開 `index.html` 可即時預覽（空白鍵播放、拉桿逐格）；加 `?review=1` 顯示字幕與時間碼。
改動畫面文字後執行 `python3 tools/subset_fonts.py` 重新產生字型子集。

字型：Noto Sans TC（SIL Open Font License）。動畫引擎：GSAP 3（Standard License）。
