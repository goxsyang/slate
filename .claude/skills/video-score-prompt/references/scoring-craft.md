# 配樂判讀與手法

這份文件講的是「看完畫面之後怎麼想」。技術數據由 `scripts/analyze_video.sh` 產出，但數據不會告訴你音樂該怎麼走——判斷才會。
判讀完、要把結論翻成精確的分層／力度／轉折動詞時，讀 `arrangement-theory.md`——本檔只講判讀原則與基礎手法，編曲層的完整詞表在那裡。

## 一、切點密度不等於戲劇重量

這是最容易搞錯、也最值得記住的一件事。

腳本會印出每 5 秒的切點密度長條圖。密度高代表剪得碎、動作激烈；但**戲劇最重的那一刻，往往落在最密集的區段之後**。

實例：某支 96 秒的動畫，44.5–50.5 秒平均每 0.25 秒一個切點（全片最碎，角色噴火＋甩武器），但真正的高潮是 63.5 秒把對手釘上牆的那一擊——那裡切點反而稀疏。

若照密度配樂，會把最大的力氣花在 45 秒，等到 63.5 秒已經沒東西可以再上一層。**密的地方要「跳」，重的地方要「壓」**，兩者用不同手段處理。

判斷戲劇重量只能靠讀畫面：誰的處境改變了？哪一格是觀眾記得的那格？那裡就是高潮，不管切點多少。

有旁白或訪談的片子還有第二個條件：**高潮必須落在人聲空窗**。峰值疊在旁白或 SOT 上一定被退。把音軌每 2–5 秒的 RMS 畫出來找空窗，方法與旁白片的編曲策略見 `arrangement-theory.md` 第九節。

## 二、力度天花板要事先分配

一支曲子只能有一個最大聲的地方。決定它在哪裡之後，其他所有爆點都必須被壓在天花板之下。

作法是**保留特定樂器給真高潮**。例如：假高潮只給銅管與大鼓，把大鑼與合唱完整留給真高潮。這樣兩處都有力量，但層級分明。

寫進 prompt 的方式是明講保留：

```
a fiery burst at 43s — powerful but deliberately held back, no choir and no gong yet
```

`no ... yet` 這個寫法很有效，它讓模型理解這是刻意的節制，而不是要它做小。

天花板定了之後，曲線本身怎麼畫（單峰、先蹲再跳、階梯、瞬間全滿、雙峰呼應）、高潮後怎麼逐層抽薄（`ease down layer by layer, gently thinning`）、力度等級的效果詞，見 `arrangement-theory.md` 第四、五節。

## 三、喜劇配樂的四個手法

### 洩氣（deflate）

喜劇裡最有效的一招。角色氣勢正盛，下一秒翻車——音樂當場垮掉。用低音管獨奏、長號滑音、滑管哨（slide whistle）。

**落差比音量重要**。前面堆得越滿，垮下來越好笑。

```
at 40s everything deflates — instant comic stop, lone bassoon and a sad trombone slide
```

### 卡通急煞（screech to a halt）

角色撞見不該看的東西、或突然發現大事不妙——音樂在樂句中間硬生生停住，像唱片被刮停。之後接一段尷尬的靜默與踮腳式撥弦。

比「音樂逐漸淡出」好笑得多，因為它有一個明確的斷點，觀眾會跟著愣住。

### mickey-mousing

動畫配樂術語：音樂緊貼畫面動作，每個動作都有對應的音。踮腳有踮腳的撥弦、伸手有滑音、跌倒有一擊。

寫進 prompt 開頭當總則最有效：`mickey-mousing every gag`。它一次定調整首曲子的行為模式，比逐一描述每個音效省字元。

### 斷崖收乾（hard cut to silence）

高潮結束後，全奏瞬間掐掉，只剩一支獨奏樂器或純靜默。

**喜劇配樂的基本功是高潮後不留餘響。** 殘響會讓觀眾繼續沉浸在剛才的情緒裡；乾淨的斷點才能讓下一個笑點成立。

以上四招是基礎款。dead stop、snap back、ta-da button、tag、record-scratch、riser／drop 成對原則等完整的打點／停止／推升／落下／回來／轉場工具箱（30 餘種，各附 prompt 句與驗證標記），以及「急停點要選幻想破滅那一格」的選格規則，見 `arrangement-theory.md` 第七節。

## 四、抒情與轉折的手法

### 主題破碎再現（broken reprise）

同一條旋律，前面是期待，後面是心碎。做法是把先前明亮的主題以放慢、破碎、走音的方式再現。

比另寫一段悲傷旋律有效得多——因為觀眾已經認識那條旋律，情緒是他們自己填進去的。

```
At 80s the innocent flute theme returns broken and slow over aching strings
```

### 同素材換語境（same material, new meaning）

一段情慾旋律在角色調情時是誘人的，等到孩子看見了、再次出現時就變成殘忍的。旋律不變，功能改變。

```
the sultry pipa returns at 74s, now cruel rather than inviting
```

### 甜中藏毒

當畫面很美但敘事上「不對」——背叛、陷阱、假意的溫柔——音樂不能寫成單純的美。在底下埋一個不協和音。

```
seductive but faintly wrong, a sour note buried underneath
```

觀眾說不出哪裡怪，但會感覺到不安。這比直接寫陰森有效，因為它保留了畫面的美。

### 不解決的收尾

角色的委屈在這場戲裡沒有出口時，音樂也不該給和聲解決。收在一個懸著的長音上。

```
Ends unresolved on a single held note
```

這是七種收尾落法之一；正格／變格／半終止／假終止／軟落／硬斷的寫法，與和聲色彩（sus、maj7、dim7、open fifths……）、轉調手法（升 key、平行大小調互換、翻頁式遠關係轉調）見 `arrangement-theory.md` 第二、三節。

## 五、判斷這場戲是喜劇還是悲劇

看**落點**，不是看素材。

一場有情慾場面的戲，如果結尾是孩子含淚崩潰，那它是悲劇，情慾段的功能是讓結尾更痛。同一場戲如果結尾是孩子嘟嘴生氣，那它是喜劇，情慾段就該做成戲謔誇張的調情。

**判斷錯了，整場戲的配樂都會錯。** 讀畫面時特別注意最後 10 秒——落點決定一切。

同時要顧及整部片的基調。如果全片都是卡通喜劇，某一場單獨走純悲劇會顯得突出而不協調；此時該做的是「委屈而不是心碎」——保留喜劇基底，情緒上酸一下就好。這個判斷要跟使用者確認，因為它取決於作品整體意圖，不是單場能決定的。

## 六、把節奏換算成 BPM

切點的平均間隔可以換算成節拍，但先決定**一刀對應幾拍**：

`BPM = 60 × (每刀拍數) ÷ (平均切點間隔秒)`

- 動作、喜劇、蒙太奇：一刀一拍。0.4s → 150（快板動作甜蜜點）、0.5s → 120、0.67s → 90
- 形象片、旁白片：一刀兩拍或一刀一小節，音樂跨過剪點。1.5s 一刀 → 80、3s 一刀 → 80（一小節）、4s → 60
- 6–8 秒一刀的純氛圍段：不給脈搏，改寫 rubato
- **換算值落在該型 playbook 的 BPM 範圍之外時**：不要硬套，改取每刀拍數（一刀兩拍／一刀一小節／一刀三拍）讓 BPM 進範圍，並在 prompt 明寫對應關係（`cut every 2 beats`、`one cut per bar`）。例：對白喜劇 1.6s 一刀，一刀一拍＝37 太慢，取一刀兩拍 75＋`cut every 2 beats`，或一刀一小節 150（快口喜劇）；蒙太奇 0.8s 一刀，一刀一拍 75 低於第 4 型的 95–125，取一刀兩拍 150。完整表在 `arrangement-theory.md` 第六節

兩個常見錯誤：

- 換算出 240 BPM 不要真的寫 240——那代表剪輯比音樂能承載的更碎。寫 120–150 加上密集打擊描述（`dense 16th-note percussion`），密度來自細分不是速度
- 慢節奏戲（平均 3.5 秒一鏡）照一刀一拍會算出荒謬的 15–20 BPM；且模型拿到 `sensual`、`action` 這類詞容易配出比畫面更急的節奏。開頭補一個 `slow` 就能拉回來

完整換算表（12 列 × 三欄）、half-time 體感（演算法 152 ≈ 體感 76）、拍號情緒、直拍 vs 搖擺、旁白片 rubato 三解法，見 `arrangement-theory.md` 第六節。

## 七、反面詞是防守，不是裝飾

模型有幾個頑固的預設傾向，只能用明確的否定擋住：

| 傾向 | 防守詞 |
|---|---|
| 自己加歌手演唱 | `Instrumental, no singing` + `force_instrumental: true` |
| 尾段自己堆高潮 | `Never rises again`、`no build`、`no swells` |
| 看到爆點就配戰鼓 | `no epic drums` |
| 把喜劇配成史詩 | `no epic`、`no drama` |
| 延續前一場的喜劇調性到悲劇場 | `no comedy` |
| 把有趣做成俗氣 | `Not corny: no slide whistle, no kazoo, no circus` |
| 浪漫做成苦情 | `Not sad, no melancholy`（並避免 `ballad` 一詞） |
| 題材召喚固定樂器（廟宇→鑼與國樂、婚禮、聖誕） | 點名否定＋正面替代並用：`no erhu, no guzheng, no dizi, no gongs` ＋ 想要的配器。一般情況仍以正面替代為主，規則見 `arrangement-theory.md` 第八節末 |
| 多段變奏片轉折被抹平 | 全域鐵則放第一段：`Every mood switch must be clearly heard — distinct, never smoothed over` |

這些詞要放在它們要管的那句附近，或集中在結尾。位置有差別：放在尾段描述之後，才管得住尾段；全域鐵則放第一段。

一個例外：需要 wordless choir 時改寫 `no lyrics, no words, wordless choir only` 且不開 `force_instrumental`——正本在 `elevenlabs-music.md` 地雷清單。

## 八、交付時附對位表

音樂拿到之後要進剪接，所以分析結論要包含「必須對齊的音樂事件」清單。差 3 幀以上就聽得出來不同步。

若產出的落點偏移，優先保住高潮與斷崖那兩點，其餘可用微幅變速（±2%）吸收。分級寫法：hit 類（撞擊、dead stop、button）±0.2 秒必保；段落轉換（曲風切換、拉升起點）±1–2 秒可容忍。半秒錨點（`13.5s`）只給 hit 類，全曲不要超過 3 個——模型對 0.5 秒精度時好時壞，全寫成 hit 反而顧不到真正的 hit。

一個實用細節：**音樂落點寫得比畫面早 0.2 秒**，聽起來才是同步的。人耳對音畫同步的感知偏向音樂略早。
